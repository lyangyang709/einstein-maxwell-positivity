# Scattering-side assumption matrix

The goal is to identify exactly which assumptions lead to which inequality.
This is not a vote on whether gravitational positivity or the Weak Gravity
Conjecture is universally valid.

## Acceptance criterion

Each non-`unresolved` cell must include a pinned version plus an exact page,
equation, or reproducible derivation. Abstract-level summaries remain `quoted`
and cannot support a universal conclusion.
